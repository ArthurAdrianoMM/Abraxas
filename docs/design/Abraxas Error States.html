os malogros·como a casa avisa quando algo falha

As falhas, em voz baixa. seis casos. nenhuma surpresa.

Quando algo falha, Abraxas explica em prosa o que aconteceu, o que isso significa, e o que fazer em seguida. Códigos de erro ficam disponíveis em letra pequena, para quem precisa.

O oráculo não acordou. o arquivo está aqui, mas recusou.

O modelo Llama 3.1 (8B · q4_k_m) não pôde ser lido para a memória. O arquivo está intacto; provavelmente o tempo de execução está em outra versão.

iii · memória esgotou err.runtime.oom

A memória bateu no teto. o modelo pediu mais do que cabe.

A geração foi interrompida porque a memória da máquina não comportou a janela de contexto desta conversa. Podemos reduzir o contexto, baixar o top-p, ou trocar para um modelo mais leve.

Para baixar Llama 3.1 (8B) com folga de respiro, precisaríamos de 8.3 GB livres. Existem 4.1 GB — apenas o suficiente para colocar o arquivo, sem espaço para o sistema operar.
